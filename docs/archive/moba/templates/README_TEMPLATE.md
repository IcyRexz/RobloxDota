## Goal
Test whether a short, readable touch-controlled 1v1 lane battle makes players want a rematch. Push with minions, destroy the enemy tower, then the core.

## Play on mobile
Join the same public server as an opponent and tap Ready. Move with the left thumbstick. Tap/hold Pulse to attack, drag and release Bolt to aim (tap for auto-aim), and tap Slip to dash. At the result screen both players can request a rematch. [State any verified audience/account restrictions and how testers joined the same server.]

## Key decisions
One mirrored hero and one lane keep the project focused. Minion pressure and tower/core objectives retain the MOBA loop. No shop/leveling keeps decisions readable. Server-owned damage/cooldowns/results support fair play; client-owned movement is validated but is not full server physics simulation. [Update to actual implementation.]
