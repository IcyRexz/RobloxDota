# One-week target; fourteen-day cap

Day 1 is your actual development start, not the pack creation date. Enter it in `TASK_STATUS.md`. Estimates total roughly 48.5 focused hours plus account waits, playtest coordination and learning time; this is an ambitious week for one developer. Seven days is a target, not a promise. Spread work across the buffer rather than relying on continuous work without rest.

- Day 1 / T01–T04: publishing feasibility, toolchain, arena, mobile movement.
- Day 2 / T05–T08: two-player membership, secure Pulse, deaths/respawns.
- Day 3 / T09–T12: objective victory, rematch, minions; first complete graybox match.
- Day 4 / T13–T16: final touch controls, bolt, dash, two actual phones.
- Day 5 / T17–T20: complete animations, readable HUD and feedback.
- Day 6 / T21–T23: security, performance, lifecycle tests and fixes. Feature freeze.
- Day 7 / T24–T26: public verification, observed testing, README and delivery.

## Checkpoints and cut policy
If a full graybox match cannot finish on day 3, stop visual polish and fix the loop. If touch is unusable on day 4, stop new features and repair input/camera. If animation publishing fails, resolve ownership/permissions or replace with licensed compatible clips early. If day-6 gates fail, use the buffer and label the build unfinished.

Cut order: decorative map detail -> camera shake/particles -> custom audio variety -> bespoke character mesh -> optional demo editing. Preserve all required actions, their animations, one lane, minions, tower/core rules, touch controls, server checks, full match/rematch, public publishing and README. Use simple authored clips and graybox art to retain functionality. Do not silently redefine a PvP arena without lane objectives as the agreed MOBA prototype.

## Days 8–14 are a contingency, not a second feature week
Days 8–10: fix gameplay/input/animation/P0 bugs. Days 11–12: repeat phone testing, tune values only. Day 13: verify final public deployment and evidence. Day 14: freeze, deliver the tested state and explicitly list any unmet requirements. External moderation/eligibility delays can exceed the cap; report them and deliver source plus blocker details at the cap without claiming successful public release. Never buy account services or pay platform fees without explicit owner authorization.

Reserve testing partners in advance. Have a private/test-access place early, while recognizing it is not the final required public experience. Back up the place and source at each daily checkpoint; retain a known good published version for rollback.
