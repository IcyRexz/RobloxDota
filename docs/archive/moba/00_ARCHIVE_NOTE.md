# Archived: 1v1 MOBA prototype (Riftbreak Duel)

On 2026-10-20 the owner switched the project from a mobile-first 1v1 MOBA to a cooperative base-defense shooter (see `docs/01_BRIEF.md`). These files are the MOBA-era documents exactly as they stood that day, kept for reference and history. They are **not** current rules.

- `01_BRIEF.md` … `10_SOURCES.md`: the MOBA design pack (`04_SCHEDULE.md` had the 7-day / 14-day schedule, which the owner dropped).
- `TASK_STATUS.md`: the full MOBA task log with every dated evidence note and decision up to the switch.
- `README.md`, `CLAUDE.md`, `templates/`: the MOBA versions of those files.

The code built in that period is still in `src/` and is being reused; `docs/03_TASKS.md` says which old pieces feed which new task.
